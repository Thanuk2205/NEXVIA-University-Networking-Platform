# PDF fonts

Bundled static regular fonts from the official Noto font projects:

- Noto Sans: https://github.com/notofonts/latin-greek-cyrillic
- Noto Sans Sinhala: https://github.com/notofonts/sinhala
- Noto Sans Tamil: https://github.com/notofonts/tamil

These fonts use the SIL Open Font License; retain `LICENSE` when redistributing them. The CV renderer registers Latin/Sinhala/Tamil fonts and selects them by script. Additional scripts require an appropriate licensed font and renderer coverage.
